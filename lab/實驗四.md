下面是一個設計給本科生的貝氏分類實驗方案，重點在於逐步引導、資料視覺化及結果分析。這個實驗以 Python 為主要工具，利用著名的 Iris 資料集（或其他資料集）進行 Gaussian Naive Bayes 分類。學生可藉此瞭解貝氏分類器的原理、如何視覺化數據、評估模型績效以及解讀結果。以下為詳細步驟：

---

## 實驗目標

- **理解貝氏定理與貝氏分類器原理：** 學生能夠理解貝氏機率的意義以及如何利用貝氏定理來推導分類模型。  
- **掌握 Python 資料分析工具：** 使用 NumPy、Pandas、Matplotlib/Seaborn 進行資料處理與視覺化。  
- **實作 Gaussian Naive Bayes 模型：** 利用 Scikit-learn 進行模型訓練、預測與評估。  
- **結果分析與討論：** 分析混淆矩陣、分類報告，並對模型效果進行深入討論。

---

## 實驗步驟

### 1. 環境準備與資料讀取

- **安裝所需套件：**  
  確保已安裝 `numpy`、`pandas`、`matplotlib`、`seaborn` 與 `scikit-learn`。

  ```bash
  pip install numpy pandas matplotlib seaborn scikit-learn
  ```

- **讀取資料：**  
  使用 Scikit-learn 提供的 Iris 資料集，或自行下載其他分類資料集。

  ```python
  from sklearn.datasets import load_iris
  import pandas as pd

  iris = load_iris()
  df = pd.DataFrame(iris.data, columns=iris.feature_names)
  df['target'] = iris.target
  df['species'] = df['target'].apply(lambda x: iris.target_names[x])
  ```

---

### 2. 資料探索與視覺化

- **資料摘要：**  
  使用 Pandas 查看資料結構與統計摘要。

  ```python
  print(df.head())
  print(df.describe())
  ```

- **特徵視覺化：**  
  利用直方圖、箱形圖觀察各特徵的分布情形。

  ```python
  import matplotlib.pyplot as plt
  import seaborn as sns

  plt.figure(figsize=(12, 8))
  for i, col in enumerate(iris.feature_names):
      plt.subplot(2, 2, i+1)
      sns.histplot(df[col], kde=True, bins=20)
      plt.title(col)
  plt.tight_layout()
  plt.show()
  ```

- **散佈圖矩陣：**  
  利用 `pairplot` 觀察不同特徵間的關係及各類別分佈。

  ```python
  sns.pairplot(df, hue='species', markers=["o", "s", "D"])
  plt.show()
  ```

---

### 3. 資料前處理與切分

- **資料切分：**  
  將資料分成訓練集與測試集（例如 70% 訓練、30% 測試）。

  ```python
  from sklearn.model_selection import train_test_split

  X = df[iris.feature_names]
  y = df['target']
  X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
  ```

- **特徵標準化（若需要）：**  
  對於 Gaussian Naive Bayes，特徵原本分布就符合連續數值，但如果資料尺度差異很大時，可考慮標準化。

  ```python
  from sklearn.preprocessing import StandardScaler

  scaler = StandardScaler()
  X_train_scaled = scaler.fit_transform(X_train)
  X_test_scaled = scaler.transform(X_test)
  ```

---

### 4. 模型建立與訓練

- **建立 Gaussian Naive Bayes 模型：**

  ```python
  from sklearn.naive_bayes import GaussianNB

  model = GaussianNB()
  model.fit(X_train_scaled, y_train)
  ```

- **預測與模型評估：**  
  使用測試集進行預測，並計算準確率、混淆矩陣及分類報告。

  ```python
  from sklearn.metrics import accuracy_score, confusion_matrix, classification_report

  y_pred = model.predict(X_test_scaled)
  acc = accuracy_score(y_test, y_pred)
  print("Accuracy:", acc)

  cm = confusion_matrix(y_test, y_pred)
  print("Confusion Matrix:\n", cm)
  print("Classification Report:\n", classification_report(y_test, y_pred))
  ```

---

### 5. 結果視覺化

- **混淆矩陣視覺化：**  
  使用 Seaborn 畫出熱度圖，直觀呈現各類別預測情形。

  ```python
  plt.figure(figsize=(6, 4))
  sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', 
              xticklabels=iris.target_names, yticklabels=iris.target_names)
  plt.xlabel('Predicted')
  plt.ylabel('True')
  plt.title('Confusion Matrix')
  plt.show()
  ```

- **決策邊界視覺化（進階）：**  
  為了方便視覺化，選取兩個主要特徵（如 petal length 與 petal width）來展示模型的決策邊界。  
  ※ 注意：僅針對低維空間，非全體特徵，僅供參考。

  ```python
  import numpy as np

  # 只取兩個特徵
  X_two = df[['petal length (cm)', 'petal width (cm)']]
  y_two = df['target']

  # 切分資料並標準化
  X_train_two, X_test_two, y_train_two, y_test_two = train_test_split(X_two, y_two, test_size=0.3, random_state=42)
  scaler_two = StandardScaler()
  X_train_two_scaled = scaler_two.fit_transform(X_train_two)
  X_test_two_scaled = scaler_two.transform(X_test_two)

  # 建立模型
  model_two = GaussianNB()
  model_two.fit(X_train_two_scaled, y_train_two)

  # 繪製決策邊界
  x_min, x_max = X_train_two_scaled[:, 0].min() - 1, X_train_two_scaled[:, 0].max() + 1
  y_min, y_max = X_train_two_scaled[:, 1].min() - 1, X_train_two_scaled[:, 1].max() + 1
  xx, yy = np.meshgrid(np.linspace(x_min, x_max, 200), np.linspace(y_min, y_max, 200))
  Z = model_two.predict(np.c_[xx.ravel(), yy.ravel()])
  Z = Z.reshape(xx.shape)

  plt.figure(figsize=(8, 6))
  plt.contourf(xx, yy, Z, alpha=0.3, cmap='Pastel1')
  sns.scatterplot(x=X_train_two_scaled[:, 0], y=X_train_two_scaled[:, 1],
                  hue=y_train_two, palette='Set1', edgecolor='k', s=100)
  plt.xlabel('Petal Length (standardized)')
  plt.ylabel('Petal Width (standardized)')
  plt.title('Decision Boundaries of Gaussian Naive Bayes')
  plt.show()
  ```

---

### 6. 結果分析與討論

- **模型績效：**  
  學生需根據混淆矩陣、準確率及分類報告討論：
  - 哪些類別被分錯？是否存在系統性偏誤？  
  - 模型在不同類別的召回率與精確率如何？是否有改進空間？

- **視覺化結論：**  
  分析直方圖、箱形圖與散佈圖，討論不同特徵對分類的重要性。  
  進一步根據決策邊界圖討論模型如何將資料分割，是否與資料分佈相符。

- **反思與擴展：**  
  學生可思考其他可能的改進方向，例如：
  - 使用其他貝氏分類器（如 Multinomial NB 或 Bernoulli NB）進行比較。  
  - 嘗試其他資料集（如文本分類資料集）並比較結果。  
  - 探討特徵工程（例如特徵選擇、特徵縮放）對模型表現的影響。
