## **決策樹問題設計**
我們要建立一棵決策樹，幫助判斷在綠行（森林）中遇到的動物是**貓、狗、兔子或狐狸**。

### **1. 設計數據**
我們設計一個簡單的表格，其中包含一些動物的特徵，例如：

| 動物    | 體型 (大/中/小) | 耳朵形狀 (長/短) | 尾巴 (長/短) | 是否會叫 (是/否) | 結果 (類別) |
|---------|---------------|----------------|------------|-------------|------------|
| A       | 小           | 長            | 短        | 否         | 兔子       |
| B       | 中           | 短            | 長        | 是         | 狗         |
| C       | 中           | 短            | 長        | 否         | 狐狸       |
| D       | 小           | 短            | 短        | 是         | 貓         |
| E       | 小           | 短            | 短        | 否         | 兔子       |
| F       | 中           | 短            | 長        | 是         | 狗         |
| G       | 小           | 長            | 短        | 否         | 兔子       |
| H       | 大           | 短            | 長        | 否         | 狐狸       |
| I       | 小           | 短            | 短        | 是         | 貓         |
| J       | 中           | 短            | 長        | 是         | 狗         |

這是一個簡單的分類問題，目標是利用這些特徵來建構一棵決策樹，以判斷新遇到的動物屬於哪一類。

---

## **2. 建構決策樹**
決策樹的核心思想是選擇一個最佳的特徵來分割數據，使得子節點的純度（Purity）最高。以下是建樹的步驟：

### **(1) 計算信息熵 (Entropy)**
決策樹常使用**信息熵（Entropy）**來衡量數據的不確定性：
\[
H(S) = -\sum p_i \log_2 p_i
\]
其中，\( p_i \) 是每個類別的比例。

例如，在所有10筆數據中：
- 兔子（Rabbit）: 3/10
- 狗（Dog）: 3/10
- 狐狸（Fox）: 2/10
- 貓（Cat）: 2/10

則初始熵為：
\[
H(S) = -\left( \frac{3}{10} \log_2 \frac{3}{10} + \frac{3}{10} \log_2 \frac{3}{10} + \frac{2}{10} \log_2 \frac{2}{10} + \frac{2}{10} \log_2 \frac{2}{10} \right)
\]

### **(2) 計算信息增益 (Information Gain)**
選擇一個特徵來進行分類，選擇能最大降低熵的特徵。信息增益計算公式：
\[
IG(S, A) = H(S) - \sum_{v \in Values(A)} \frac{|S_v|}{|S|} H(S_v)
\]
其中：
- \( A \) 是某個特徵
- \( S_v \) 是該特徵的某個值所對應的數據子集
- \( H(S_v) \) 是該子集的熵

**示範：計算特徵「是否會叫」的資訊增益**
- 會叫（Yes）：包含 [狗, 狗, 貓, 貓]（2狗、2貓）
- 不會叫（No）：包含 [兔子, 兔子, 兔子, 狐狸, 狐狸]（3兔子、2狐狸）

分別計算每個子集的熵，然後計算信息增益。

選擇信息增益最高的特徵作為根節點，然後繼續對子節點執行相同過程，直到所有葉節點純度達到最大或滿足停止條件。

---

## **3. 剪枝（Pruning）**
剪枝是為了防止決策樹過擬合（Overfitting），主要有兩種方法：
1. **預剪枝（Pre-Pruning）**：在建樹時設定停止條件，例如當信息增益小於某個閾值時停止分裂。
2. **後剪枝（Post-Pruning）**：先完整生成決策樹，然後透過交叉驗證或錯誤率來修剪不必要的分支。

**示範：使用後剪枝**
假設決策樹最後一層的一個分支區分「兔子」與「狐狸」，但這個分支只包含少量訓練樣本，那麼我們可以考慮將其合併，以減少模型複雜度。

## **4. 實驗與程式實作**
### **使用 Scikit-learn 建立決策樹**
我們可以讓學生使用 Python `scikit-learn` 庫來構建決策樹，並視覺化結果：
```python
from sklearn.tree import DecisionTreeClassifier, plot_tree
import matplotlib.pyplot as plt
import pandas as pd

# 建立數據
data = {
    '體型': ['小', '中', '中', '小', '小', '中', '小', '大', '小', '中'],
    '耳朵形狀': ['長', '短', '短', '短', '短', '短', '長', '短', '短', '短'],
    '尾巴': ['短', '長', '長', '短', '短', '長', '短', '長', '短', '長'],
    '是否會叫': ['否', '是', '否', '是', '否', '是', '否', '否', '是', '是'],
    '類別': ['兔子', '狗', '狐狸', '貓', '兔子', '狗', '兔子', '狐狸', '貓', '狗']
}

df = pd.DataFrame(data)

# 將文字特徵轉換為數值
df_encoded = df.apply(lambda x: pd.factorize(x)[0])

# 建立決策樹
X = df_encoded.drop(columns=['類別'])
y = df_encoded['類別']
tree = DecisionTreeClassifier(criterion='entropy', max_depth=3)
tree.fit(X, y)

# 視覺化決策樹
plt.figure(figsize=(12, 6))
plot_tree(tree, feature_names=X.columns, class_names=['兔子', '狗', '狐狸', '貓'], filled=True)
plt.show()
```
這樣，學生可以看到決策樹的結構，並進行剪枝實驗。

   - 繼續分裂直到純度達到最大或滿足停止條件。
3. **剪枝**：
   - **預剪枝**（避免過度分裂）。
   - **後剪枝**（減少過擬合）。
